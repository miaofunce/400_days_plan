## 0. 热身：char 栈（10 分钟）

你 Day06 的 `stack.c` 是 `int data[MaxSize]`。复制一份，把元素类型换成 `char`：

```c
#define MaxSize 64
struct CharStack{
	char data[MaxSize];
	int top;
};
void initStack(struct CharStack *s);
int  Push(struct CharStack *s, char c);
int  Pop(struct CharStack *s, char *c);
int  isEmpty(struct CharStack *s);
char Top(struct CharStack *s);      /* 只看不弹 */
```

`Top` 是新函数：**只读栈顶，不动 `top`**。它和 `Pop` 的区别，是今晚第一个要亲手敲清楚的东西——中缀转后缀全程都在用它。

## 1. 后缀表达式求值（25 分钟）

输入空格分隔的后缀串，只含单个数字和 `+ - * /`。
规则：读到数字入栈；读到运算符弹出两个数，**先弹出来的是右操作数**，算完压回去。

```c
int evalPostfix(char *expr);        /* "1 2 3 * +" -> 7 */
```

这一步只需要一个栈，纯复习，你写过的 Push/Pop 直接搬过来用。

> ⚠ **坑 1**：`a - b` 里先 pop 出来的是 `b`。写反了，`8-3` 会算成 `3-8`。

## 2. 中缀转后缀（40 分钟）

```c
void infixToPostfix(char *infix, char *postfix);   /* "1+2*3" -> "1 2 3 * +" */
```

规则（调度场算法的简化版，只处理个位数、四则、括号）：

- 数字 → 直接输出
- `(` → 入栈
- `)` → 弹栈输出，弹到 `(` 为止；`(` 弹出但**不输出**
- 运算符 → 弹掉所有**优先级 ≥ 自己**的运算符并输出，然后自己入栈
- 扫完 → 栈里剩下的全部弹出输出

```c
int prec(char op);                  /* + - 返回 1，* / 返回 2 */
```

> ⚠ **坑 2，今晚最关键的一个**：优先级比较写 `>=` 还是 `>`。
> 写成 `>`，`8-3-2` 会算成 `8-(3-2)=7`；必须是 `>=`，才是左结合 `(8-3)-2=3`。
> 一个符号的差别，整个结果就错——和你上次把 `isFull` 里的 `q->front` 写成 `0`，是同一类错误：**细节错了，逻辑全塌。**
