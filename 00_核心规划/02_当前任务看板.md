## A. 顺序队列 → 先写个"错的"（30min）

不要一上来就写循环队列。先写**朴素版**，让它撞墙 —— 假溢出这四个字你就不用背了。

```c
#define MaxSize 5
struct Queue{
	int data[MaxSize];
	int front;   /* 队头元素下标 */
	int rear;    /* 队尾元素的下一个位置 */
};
void initQueue(struct Queue *q);
int  EnQueue(struct Queue *q, int val);    /* 满返回 0 */
int  DeQueue(struct Queue *q, int *val);   /* 空返回 0 */
int  isEmpty(struct Queue *q);
```

朴素版规则就两条：入队 `q->data[q->rear++] = val`，出队 `*val = q->data[q->front++]`。

然后跑这个序列，**把输出抄到纸上**：

```c
EnQueue 10,20,30,40      /* 队列: 10 20 30 40, front=0 rear=4 */
DeQueue  -> 10           /* front=1 */
DeQueue  -> 20           /* front=2 */
EnQueue 50               /* rear=5 —— 还能进吗？ */
```

队列里只剩 2 个元素，下标 0、1 是空的，但 `rear == MaxSize` 会判满、拒绝入队。**这就是假溢出。**
写一句话在文件顶部注释：*"数组没满，但 rear 走不动了"* —— 这句话就是循环队列存在的理由。

## B. 循环队列（60min）

把数组当成一个环，用 `% MaxSize` 让 `front` / `rear` 绕回去。今天唯一的核心，自己推：

- 入队后 `rear` 怎么动？
- 出队后 `front` 怎么动？
- **判空和判满都会出现 `front == rear`，怎么区分？**

用王道标准做法：**牺牲一个存储单元**（`MaxSize=5` 时最多存 4 个）。

```c
#define MaxSize 5
struct SqQueue{
	int data[MaxSize];
	int front;   /* 队头元素下标 */
	int rear;    /* 队尾元素的下一个位置 */
};
void initQueue(struct SqQueue *q);
int  EnQueue(struct SqQueue *q, int val);
int  DeQueue(struct SqQueue *q, int *val);
int  isEmpty(struct SqQueue *q);
int  isFull(struct SqQueue *q);
int  Length(struct SqQueue *q);
```

## C. 链队列（60min）

```c
struct LinkNode{
	int data;
	struct LinkNode *next;
};
struct LinkQueue{
	struct LinkNode *front;   /* 指向头结点（不存数据） */
	struct LinkNode *rear;    /* 指向队尾结点 */
};
void initQueue(struct LinkQueue *q);        /* 先申请头结点，front = rear = 头结点 */
int  EnQueue(struct LinkQueue *q, int val);
int  DeQueue(struct LinkQueue *q, int *val);
int  isEmpty(struct LinkQueue *q);
void DestroyQueue(struct LinkQueue *q);     /* 含头结点一起 free */
```

只有一个坑，但坑很深：**出队的是最后一个元素时，`rear` 会变成野指针**，下一次入队直接崩。
自己先想清楚"什么时候必须把 `rear` 拽回来"。`DestroyQueue` 放到最后写，它顺便帮你验证有没有漏 `free`。

## 验收标准（对着跑，别凭感觉）

`CircularQueue.c` 必须通过这张表（`MaxSize = 5`，最多存 4 个）：

| 操作 | 期望返回 |
|---|---|
| `initQueue` 后 `isEmpty` | 1 |
| `EnQueue` 10, 20, 30, 40 | 1, 1, 1, 1 |
| `EnQueue` 50 | **0（队满）** |
| `Length` | 4 |
| `DeQueue` → | 1，值 10 |
| `DeQueue` → | 1，值 20 |
| `Length` | 2 |
| `EnQueue` 50, 60 | 1, 1 ← **环形回绕，最容易写错的一步** |
| `Length` | 4 |
| `DeQueue` ×4 → | 30, 40, 50, 60 |
| 再 `DeQueue` 一次 | **0（队空）** |
| `isEmpty` | 1 |

`LinkQueue.c` 的照妖镜序列：

```
EnQueue 1,2,3 → DeQueue 得 1 → DeQueue 得 2 → DeQueue 得 3
→ isEmpty 应为 1
→ 再 EnQueue 99 一次不崩 → DeQueue 得 99
→ DestroyQueue 不崩
```

倒数第三步就是抓 `rear` 野指针的。**空队出队、满队入队一律返回 0，不许崩** —— 和 Day06 `pop` 先判空是同一个道理。
