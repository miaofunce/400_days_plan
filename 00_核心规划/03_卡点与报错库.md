# 核心卡点与顿悟记录
1. **关于指针传参**：为什么 `swap(x, y)` 不能改变原值？因为C语言是按值传递。必须用 `swap(&x, &y)` 传地址，函数里用 `*a = *b` 才能改变真实内存。
2. **关于scanf**：为什么 `scanf("%d", &arr[i])` 要加 `&`？因为 scanf 需要知道往哪块内存写数据，必须给地址。但读取字符串（char数组）时不用加 `&`，因为数组名本身就是地址。
3. **关于结构体访问**：`.` 用于普通结构体变量（如 `class1[i].name`），`->` 用于结构体指针（如 `p->name`）。`p->name` 等价于 `(*p).name`。
4. **关于链表删除的边界顺序**：先判空、再解引用。指针可能为 `NULL` 时，绝不能先写 `q = p->next` 再判 `p == NULL`，否则越界时程序直接崩溃。正确顺序：循环移动指针 → `if(p == NULL || p->next == NULL) return 0;` → 再取 `q = p->next`。（2026-10-08 修复 Linklist.c 时总结）
